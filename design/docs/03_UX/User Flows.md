# 13. User Flows

## Overview

User flows define the sequence of interactions users take to accomplish a specific goal.

Each flow is designed to minimize cognitive load, reduce unnecessary steps, and provide clear guidance throughout the healthcare experience.

The redesigned flows prioritize user intent over platform features, ensuring users always know what to do next.

---

# Primary User Flows

The platform supports five core healthcare journeys.

1. Find Care
2. Book Consultation
3. Get Medication
4. Manage Health
5. Continue Care

---

# Flow 01 — Find Care

### Goal

Help users quickly identify the right healthcare service.

```text
Landing

↓

How can we help you today?

↓

Choose Intent

↓

Recommended Care Path

↓

Treatment Details

↓

Continue
```

### User Intent

- I have symptoms
- I need medication
- I need a doctor
- I need advice

### Success Criteria

The user confidently identifies the correct healthcare pathway within one minute.

# Cross-Flow Patterns

Every user flow follows the same interaction model.

```text
Intent

↓

Guidance

↓

Action

↓

Confirmation

↓

Progress

↓

Completion

↓

Follow-up
```

This consistency reduces learning effort across the platform.

---

# UX Patterns

The following interaction patterns appear throughout the product.

## Guided Decisions

Present recommended actions instead of overwhelming users with options.

---

## Progressive Disclosure

Reveal information only when it becomes relevant.

---

## Contextual Actions

Display actions based on the user's current stage in the journey.

---

## Persistent Status

Always show where users are and what happens next.

---

## Recovery Paths

Provide clear ways to edit information, return to previous steps, or contact support.

# User Flow Summary

The redesigned flows transform healthcare tasks into guided experiences.

Instead of asking users to navigate a complex healthcare system, the platform acts as a trusted guide—helping them discover care, receive treatment, manage their health, and stay engaged over time.

Every flow is built around one principle:

> **The platform should adapt to the user's healthcare journey—not the other way around.**
